# Техническое задание

## 1. Общие сведения

### 1.1 Наименование проекта
**music_box**

### 1.2 Назначение проекта
Сайт предназначен для обмена музыкой между пользователями в сети интернет, путём предоставления физического пространства
на удалённом сервере 

### 1.3 Платформа
- Серверная часть: Windows / Linux
- Клиентская часть: любой современный веб-браузер

## 2. Функциональные требования

### 2.1 Регистрация и аутентификация пользователей

#### 2.1.1 Регистрация
- Возможность самостоятельной регистрации новых пользователей
- Требования к логину: от 3 до 50 символов
- Требования к паролю:
  - Минимальная длина — 8 символов
  - Хотя бы одна заглавная буква (A-Z)
  - Хотя бы одна строчная буква (a-z)
  - Хотя бы одна цифра (0-9)
  - Хотя бы один специальный символ (`!@#$%^&*(),.?":{}|<>`)
- Автоматическое присвоение роли "пользователь" (user)

#### 2.1.2 Вход в систему
- Аутентификация по логину и паролю
- Перенаправление на главную страницу сайта с отображением успешной авторизации

#### 2.1.3 Выход из системы
- Завершение сессии пользователя
- Перенаправление на главную страницу с отображением сообщения об выходе 

### 2.2 Управление треками (администратор)

#### 2.2.1 Панель администратора
- Просмотр списка всех треков

#### 2.2.3 Удаление треков
- Мягкое удаление (трек помечается как `deleted_at = дата в UTC`)

### 2.3 Загрузка треки на сайт

#### 2.3.1 Загрузка файла
- Поддерживаемый формат: `.mp3`, `.wav`, `.ogg`, `.m4a`
- Требования к названию трека: от 1 символа
- Требования к исполнителю трека: от 1 символа
- Необязательное поле `Теги` (может быть пустым)
- Кнопка для загрузки трека с устройства
- Список популярных тегов
- Кнопка `загрузить` для загрузки трека на сайт

#### 2.3.2 Процесс загрузки
- трек добавляется в директорию `uploads`
Применяемые трансформации к названию трека:
- Добавление к названию трека даты и времени его загрузки

#### 2.3.3 Результат
- Отображение загруженного трека на главной странице сайта и в разделе `моя музыка`
- Возможность скачать трек, добавить в свои плейлисты, добавить в избранное, либо удалить (если авторизованный пользователь - владелец загруженного трека)
- Возможность воспроизведения треков с регулированием уровня громкости
- Возможность отображение треков по тегам 

#### 2.3.4 Статистика треков 
- Количество прослушиваний трека
- Дата загрузки трека на сайт
- Имя пользователя, загрузившего трек

### 2.4 Профиль пользователя

#### 2.4.1 Информация о пользователе
- Отображение имени пользователя в navbar

#### 2.4.3 Плейлисты пользователя
- Список всех плейлистов пользователя (название, описание, количество треков)
- Кнопка открытия и удаления плейлиста для владельца плейлиста

#### 2.4.4 Создание плейлиста
- Название плейлиста
- Описание Плейлиста
- Флажок публичный плейлист (если нажат, то публичный, иначе приватный)
- Кнопка создания плейлиста

#### 2.4.5 Мои треки
- Список треков (название, исполнитель, тег, дата добавления, количество прослушиваний)
- Возможность воспроизведения трека
- Возможность увеличения/уменьшения уровня громкости трека
- Кнопки "скачать" для скачивания трека
- Кнопка "удалить" для удаления трека

### 2.5 Хранение файлов

#### 2.5.1 Структура хранения
- Структура : `uploads/XX_YY_filename`
- `XX` — Дата добавления файла
- `YY` — Время добавления файла
- `filename` — Название файла  
- Пример: `uploads/20260616_213834_КИНО-Перемен.mp3`

## 3. Нефункциональные требования

#### 3.1 Безопасность
- Хранение паролей в хэшированном виде
- Изоляция сессий пользователей
- Запрет удаления чужих файлов за исключением администратора

#### 3.2 Кроссплатформенность
- Поддержка Windows (пути через `\`)
- Поддержка Linux (пути через `/`)

#### 3.3 Стиль сайта
- Возможность включения/отключения на сайте тёмной темы

### 5. Маршруты (Routes)

| URL | Метод | Описание | Доступ |
|-----|-------|----------|--------|
| `/login` | GET, POST | Вход в систему | Анонимный |
| `/register` | GET, POST | Регистрация | Анонимный |
| `/logout` | GET | Выход | Авторизованный |
| `/` | GET | Главная страница сайта | Анонимный |
| `/my-music` | GET, POST | Треки, которые загрузил текущий авторизованный пользователь | Авторизованный |
| `/favorites>` | GET | Треки, которые добавил текущий авторизованный пользователь в избранное | Авторизованный |
| `/favorite/<int:track_id>/toggle` | GET | Добавление трека в избранное и удлание трека из избранного | Авторизованный |
| `/track/upload` | GET, POST | Загрузка трека на сайт | Авторизованный |
| `/track/delete/<int:track_id>` | GET, POST | Удаление трека с сайта (Через флаг, что он удалён) | Авторизованный/Администратор |
| `/track/<int:track_id>/increment-play` | GET | Подсчёт числа воспроизведений трека | Анонимный |
| `/uploads/<filename>` | GET | Отображение файла | Анонимный |
| `/playlists` | GET | Отображение плейлистов | Анонимный |
| `/playlist/create` | GET, POST | Создание плейлиста | Авторизованный |
| `/playlist/<int:playlist_id>` | GET | Отображение приватного плейлиста | Авторизованный |
| `/playlist/<int:playlist_id>/add-track/<int:track_id>` | GET | Добавление трека в плейлист | Авторизованный |
| `/playlist/<int:playlist_id>/remove-track/<int:track_id>` | GET | Удаление трека из плейлиста | Авторизованный |
| `/playlist/<int:playlist_id>/delete` | GET | Удаление плейлиста | Авторизованный |
| `/tags` | GET | список тегов | Анонимный |
| `/toggle-theme` | GET | Переключение темы сайта | Анонимный |


## 6. Пользовательский интерфейс

### 6.1 Страницы

| Страница | Описание |
|----------|----------|
| **Все треки** | Главная страница на которой отображается вся музыка |
| **Регистрация** | Форма с именем пользователя, почтой и паролем, отображение требований к паролю |
| **Вход** | Форма с именем пользователя и паролем |
| **Теги** | Поиск треков по тегам |
| **Плейлисты** | Отображает список публичных плейлистов, если пользователь авторизован также отображает его плейлисты и даёт возможность его удалить; есть кнопка создать новый плейлист |
| **Название плейлиста** | Отображает список треков данного плейлиста. Владелец плейлиста может изменять его содержимое |
| **Моя музыка** | Отображает список музыки, которую загрузил пользователь (видна только авторизованым пользователям) |
| **Загрузить** | Страница загрузки треков на сайт (видна только авторизованым пользователям)|
| **Избранное** |Отображает избранные треки пользователя (видна только авторизованым пользователям) |

### 6.2 Навигация
- Верхнее меню (navbar):
  - Логотип (слева) → переход на главную страницу 
  - Ссылка на админ-панель (только для администраторов)
  - Кнопка "Войти" и "Регистрации" для не авторизованных пользователей
  - Имя пользователя + Кнопка "Выйти", если пользователь авторизован
  - Кнопка переключения темы сайта (с тёмной на светлую и наоборот)
    

## 7. Допущения
- Пользователь загружает корректные звуковые файлы, а не другие с измеённым расширением
- Браузер поддерживает HTML5 и JavaScript
